# Markdown 预览焦点与跨范围删除

整个 Markdown 预览此前以 Button 角色暴露给系统辅助功能，容易呈现为一个可聚焦的大控件。现改为普通内容容器 GenericContainer，保留其中可选择的文本标签，不使用按钮语义；双击编辑与右键菜单通过实际鼠标事件判断。

混合预览模式中，各源码范围独立使用 egui TextEdit，光标在范围开头时 Backspace 无法访问前一段文本，末尾 Delete 也无法删除后一段。现在检测这两种边界动作，将局部光标转换为整篇源码字节位置，自动进入整篇源码编辑并将原键盘事件交给现有 TextEdit 处理。没有自行删除原范围、直接剪切字符串或合并文件关联；修改走原来的整篇文本映射、撤销和自动保存机制。可点击“恢复 Markdown 预览”返回渲染。

回归覆盖：相邻普通文本开头 Backspace 可删除前面 Markdown 中的字符并撤销；Markdown 源码末尾 Delete 可继续删除下一区域字符；Markdown 源码全选后退格清空，离开后没有残留预览块；无障碍树中预览为普通容器；既有双击、焦点、拖选和复制回归保持通过。
