# Markdown 预览选择与复制

Markdown 渲染后可直接拖选文字，以 Ctrl/Cmd+C、编辑菜单“复制”或右键“复制选中文字”复制选中的显示文字。只输出纯文本，不输出颜色、字体或 HTML。右键“复制 Markdown 源码”保留完整原始 Markdown 的复制入口。双击预览仍进入源码编辑。

改动：启用 CommonMark 控件的 egui 原生文字选择，移除拦截文字拖选的点击覆盖层，改为观察预览范围内的双击及右键。通过 egui 的 TextSelectionSettled 事件缓存已选文字，菜单点击期间保留，避免切换到菜单就丢选区；后续内容点击、源码输入、切换工作区等会失效。macOS 原生菜单的复制连接到预览选择；预览选区不允许剪切/粘贴误改上一个源码输入框。查找框和整篇源码模式仍走原有编辑命令。

`tests/markdown_ui.rs` 新增真实鼠标拖选标题、快捷键复制、编辑菜单复制、右键复制、原文不变及仍处于预览的集成验证；原有双击编辑、失焦预览、原始源码复制、空范围等回归保留。

macOS ARM64 全量 112 项测试、格式检查及严格 clippy 通过；AppKit 系统菜单探针通过；release 已更新到用户 Applications 的唯一 Tabloom.app。Linux ARM64/X11 完整回归通过，包含 112 项测试和原生文件/剪贴板/恢复/渲染/1 MiB 验证，最后源码状态另运行测试和 clippy 校验。Windows、Linux x86_64 与 Wayland 本轮未实际验证。新拖选/复制交互通过控件事件注入测试，未宣称实体键鼠人工验收。
