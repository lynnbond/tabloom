# Tabloom 开发文档

本项目面向开发者提供本地优先的 Rust 原生纯文本编辑器：一个标签对应一个工作区，每个工作区显示为一份连续文档，通过整行选区配置独立语法范围。

当前已完成**需求拆解、第一步环境检查、第二步核心骨架、第三步自动保存、第四步基础编辑及第五步文件互操作**。已有可启动、可本地保存和恢复的原生应用；第六步已执行本机验收和 1MiB 性能测量；Windows、Wayland 和实体输入法仍待对应环境。
