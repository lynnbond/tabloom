## 自动化测试矩阵

| 范围 | 测试内容 | 预期证据 |
| --- | --- | --- |
| 模型 | UUID 归属、区域增删重排、删除最后区域、工作区隔离、活动 ID 修正 | 单元测试 |
| 序列化 | 多工作区/区域完整 round-trip，中文/Emoji/Tab/LF/CRLF/CR | 原始字符串相等 |
| 独立语言 | 同一工作区 JSON、SQL、Go、Plain Text；切换语言不改文本 | 模型与高亮测试 |
| 高亮 | 每项声称支持的语法可查到真实定义、内容未改变、主题切换 | 语法注册表测试 |
| 持久化 | 无文件初始化、原子清单保存/加载、活动标签、区域顺序/比例、关闭/重开 | 临时目录文件存储测试 |
| 隔离和删除 | 关闭/删除 A 后 B 完整；永久删除级联且活动状态合法 | 集成测试 |
| 迁移恢复 | 版本升级、未知高版本拒写、损坏原件保留、有效/无效备份 | 可重复 fixture 测试 |
| 保存错误 | 真实路径故障、清单提交失败保持旧状态、不清 dirty、不伪报成功 | 返回错误和 UI 状态断言 |
| 防抖 | 连续输入合并、最长等待触发、失败重试、旧 revision 不覆盖新修改 | 可控时钟的调度测试 |
| 剪贴板 | 选区 Unicode 边界、原始换行、无标题/行号/高亮标签 | 提取函数与平台文本输出断言 |
| 查找替换 | 空查询、大小写、多字节字符、前后回绕、当前/全部替换、撤销 | 匹配逻辑和编辑适配测试 |
| 文件 | UTF-8/BOM、UTF-16 LE/BE、无效输入、导出/写回、读写失败 | 文件字节及文本断言 |
| 文件隔离 | 自动保存只更新内部工作区文件；未执行显式保存时原文件字节不变 | 集成测试 |

保存失败测试不能仅靠 chmod：高权限运行下可能仍可写，优先使用只读连接或可控故障注入。

## 必须执行的构建检查

```sh
cargo fmt --all -- --check
cargo check
cargo test
cargo clippy --all-targets --all-features -- -D warnings
cargo build --release
```

所有命令须在初始化 Cargo 项目、设置实际工具链后运行。每项记录命令、平台、结果和必要日志，不以仅有编译结果替代交互验证。

## 桌面验收流程

1. 首次启动直接输入；新建两个标签，各建多个区域，分别输入 JSON、SQL、Go 和中文笔记。
2. 验证切换标签、焦点、语言和撤销栈独立；拖动高度和上下移动。
3. 等待自动保存，关闭再启动，核对文本、语言、顺序、布局、主题、字号、活动标签。
4. 关闭一个标签，在最近关闭中重开；永久删除时要求明确确认，其他标签完整。
5. 每区域执行选择、全选、复制、剪切、粘贴和撤销重做；将含 Tab/中文/Emoji/多行内容粘贴到外部纯文本编辑器并比较。
6. 查找计数、前后导航、替换和撤销；焦点移到查找输入框时快捷键不误改编辑区域。
7. 打开真实文件，编辑后确认只更新恢复副本；显式保存才写回；临时区 Ctrl/Cmd+S 不弹保存框；主动导出可选择路径。
8. 注入保存失败，错误持续可见，编辑仍可继续，恢复写权限后能重试成功；测试退出时失败处理。
9. 在完成保存后强制终止进程并重启，验证已提交清单恢复；单独验证未提交防抖窗口的实际边界。

## 性能与最终交付

使用确定生成的约 1MB Unicode/普通文本，在多个工作区、多个区域场景记录加载、切换、输入、语法切换、保存时长与可感知卡顿。高亮降级和文件大小限制依据测量说明，不宣称无限大小或无限区域性能。
