# Tabloom 样式候选稿

本目录保留最初的静态视觉提案。四套现已落地，实际效果与验证见 [实施记录](../../15-themes-report.md)。保留多标签、连续文档、独立语法范围和底部语言选择。

| 方案 | 方向 | 细节 |
| --- | --- | --- |
| A 石墨极简 | 深色、低干扰 | 下划线活动标签、薄荷绿强调、灰黑底色 |
| B 纸白原生 | 浅色、macOS 感 | 标签融入白色文档、柔和蓝色、清晰层次 |
| C 深海工作台 | 深色、开发工具感 | 紧凑标签、蓝灰底色、低亮度蓝紫强调 |
| D 暖砂留白 | 浅色、文档感 | 暖灰纸色、少线条、不显示行号 |

打开 `index.html` 比较四版；点击单独查看或按 1–4 放大，按 0 返回总览。PNG 用于直接预览，SVG 为可编辑原稿。行号和配色均属于视觉提案，不代表新增功能已实现。

```sh
open docs/designs/style-options/index.html
```

所有稿件都缩小菜单/标签字号、减少描边，关闭按钮采用无背景的小叉，新增按钮改为标签栏加号；正文没有区域卡片或边框。最终 egui 实现以用户选择为准。
