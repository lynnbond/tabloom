## 改动

- `src/ui/theme.rs`：集中配色、字体大小、间距、面板、控件、弹窗、选区和光标；四套均由代码绘制，无新增依赖或运行时位图。
- `src/app.rs`：外观菜单、轻量标签栏、无胶囊背景关闭按钮、标签栏加号、缩小菜单、简洁页脚及切换后的选区/焦点恢复。
- `src/settings/mod.rs`：GUI 无关 Appearance 枚举及可选偏好字段；保留旧 dark 字段兼容旧快照，缺少新字段时深色对应 A、浅色对应 B。新选择同时同步旧布尔值。文件格式仍为 1，无需再次迁移。
- `src/ui/editor_region.rs`：文档留白、A/B/C 行号、D 无行号；缓存键包含主题 ID，因此两个深色或两个浅色主题之间切换也会正确重新着色。
- `src/editor/highlighting.rs`：保留 syntect 语法解析，对已有 token 色值应用主题调色板；原文及语法范围不变，继续保留纯文本延迟加载路径。
- `tests/themes.rs`：四主题菜单切换、选区/撤销保留、文本和语法/文件状态隔离、旧偏好兼容与重启恢复。
- `examples/document_smoke.rs`：新增可选 A/B/C/D 参数，真实窗口展示并验证持久化。Linux 验证脚本及 CI 已覆盖四套截图探针。

行号通过绘制已有 Galley 行实现，仅绘制视口中行号，不写入 TextEdit 缓冲。文档仍只有一个可跨范围选择的编辑器，没有新增区域边框、标题卡或分割线。行号跟随文档滚动，当前没有单独的行号显示开关；D 默认隐藏。

## 使用

正常退出已有实例后，打开新包，再进入“外观”选择：

```sh
open target/release/Tabloom.app
```

已有 JSON 工作区可直接读取；旧 SQLite 用户仍沿用此前的一次性迁移流程，本次没有改动该流程，也没有自动操作正式用户数据。
