# Markdown 自动预览与源码编辑

行为：已配置为 Markdown 的语法范围默认渲染。双击预览或使用预览右键菜单进入原始 Markdown 编辑；焦点离开该范围、切换标签/应用或按 Esc 后恢复预览。不同 Markdown 范围独立切换，保持无边框的文档风格。显示切换不转换、格式化或重新序列化文本。数据模型和文件存储格式未变化。

`src/ui/markdown.rs` 负责临时显示状态和范围源码编辑，使用 egui_commonmark 0.26.0 渲染。该版本明确匹配 egui 0.37（[官方变更记录](https://github.com/lampsitter/egui_commonmark/blob/master/CHANGELOG.md)），实际依赖固定在 Cargo.toml/Cargo.lock；关闭默认特性，不安装网络/文件图片加载器。代码块、标题、强调、列表、引用、表格等由成熟的 CommonMark 解析和 egui 控件完成，不依赖 WebView。

`src/app.rs` 将原有纯文本剪贴板、编辑菜单、格式操作和自动保存连接到稳定区域 ID。源码编辑后会更新原始 Region，并同步整篇源码的撤销快照和全局选择位置。预览提供“复制 Markdown 源码”，不会复制 UI 装饰或富文本。显示状态不持久化，重启恢复原始 Markdown 后默认预览。

没有 Markdown 的标签继续使用原有单个 TextEdit。混合预览时多个源码输入有独立焦点/撤销；底部提供“编辑整篇源码 / 恢复 Markdown 预览”，跨范围选择、全篇复制和格式重新划分通过该入口完成。查找替换显示并操作整篇原始源码。预览状态没有源码行号，整篇源码模式保留原有能力。为避免切换焦点使后续范围移动，本次标签显示期间保留范围高度；切换标签后重算。

限制：Markdown 超过 256 KiB 时以源码代替预览并显示提示；不自动猜测普通文本语言，不加载本地/网络图片，不执行 HTML/脚本，也没有数学公式渲染。临时视图高度与光标不跨重启保存。

- 新增 `tests/markdown_ui.rs` 六项控件集成测试：默认预览/双击源码/失焦恢复、源码模式与 Esc、局部撤销及相邻文本隔离、复制原始 Markdown、多 Markdown 范围切换、自动保存 dirty 标记/提交/销毁状态/磁盘恢复并重新预览。覆盖中文、Emoji、Tab、CRLF 和 LF。
- macOS ARM64：格式检查、全目标编译、109 项测试和严格 clippy 通过。原生渲染探针已增加 Markdown + JSON + SQL 混合内容，文本与恢复验证通过；截图见 [Markdown 预览](screenshots/markdown-preview.png)。该截图来自隔离示例，因此仍使用示例的窗口内菜单；正式应用继续使用系统顶栏菜单。
- 原生系统菜单探针回归通过，涵盖快捷键、撤销/重做、查找/替换、写入失败取消退出与恢复后安全退出。修正了探针对 AppKit 菜单回调必须“下一帧同步送达”的错误假设，事件循环保持运行并留出动画分派时间；没有改变产品菜单动作。
- Linux ARM64/X11：完整容器回归通过，109 项测试、fmt/check/clippy、四主题混合预览渲染、目录、主程序启动、保存/崩溃恢复、文件冲突、真实 X11 剪贴板和 1 MiB 文本探针均通过。
- Windows、Linux x86_64、Wayland 及实体键鼠/中文输入法本轮未实际验收；控件交互由 egui_kittest 注入，原生窗口渲染与 AppKit 菜单均实际运行。

正式 release 已更新到 `~/Applications/Tabloom.app`，保留唯一应用入口、原生图标和 macOS 系统菜单；没有关闭旧实例或修改用户工作区。正常退出旧实例并重新打开即可使用。

## 空范围占位修复

移除“空 Markdown · 双击开始编辑”生成提示。其他内容旁的空白 Markdown 范围不创建预览、焦点装饰或预留高度；其原始空格、Tab 和换行保持原样。整篇为空时显示普通源码输入位置，获得焦点后保持源码编辑，避免输入第一个字符就自动切回预览。源码删空并失焦后不再留下不可用退格删除的提示块。

macOS 本轮 8 项 Markdown 控件测试及严格 clippy 通过，包括新增的尾部空范围不显示且不改文本、整篇空白可连续输入两项回归；release 应用包已更新。未重复运行全量测试或其他平台回归。
