# 选中行右键设置格式

选择完整一行或多行后，在文档右键菜单中直接选择格式。自动建立或调整后台语法范围并设置语言，不再要求先创建区域，再到状态栏设置语言。语言菜单支持滚动，显示现有语法库实际提供的语言。

底部状态栏仅显示“格式：JSON”等文字；选区跨越不同语言时显示“格式：混合格式”。无选区时显示光标所在范围的语言。没有下拉选择控件。高级“编辑 → 区域操作”和整行转换仍保留。

右键按下、释放及弹出菜单期间保留选区；格式操作使用菜单捕获的原始字节范围。部分行和空选区不能设置格式；跨关联文件的限制沿用原模型。操作只改变后台范围及语法配置，不改变文本、换行、中文、Emoji 或制表符，走现有自动保存和恢复流程。

## 关键代码

- `src/ui/editor_region.rs`：右键语言列表、选区保持、捕获格式命令。
- `src/app.rs`：范围与格式一次应用、只读状态栏及混合格式显示。
- `src/ui/text.rs`：集中中文文案。
- `tests/ui.rs`：独立格式、Unicode/CRLF、部分行禁用、只读状态栏、混合选择和文档撤销。
- `tests/persistence_ui.rs`：真实右键设置 JSON/SQL 后保存，销毁状态并从磁盘恢复。
