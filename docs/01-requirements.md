# 需求与边界

## 核心体验

启动后立即可输入，无需命名或指定保存位置。关闭应用保留全部工作区；关闭标签只是将工作区移至最近关闭。每个工作区具有独立的多个文本区域，每个区域分别保存内容、语言、顺序和活动状态，在 UI 中作为隐式语法范围。

默认中文界面，纵向结构为菜单、可滚动标签栏、一个无边框连续文档编辑器和状态栏。选中至少一整行后可转换为独立语法范围，不显示区域标题栏和高度分隔线。新建标签后自动聚焦。

## 功能范围

| 范围 | 必须实现的行为 |
| --- | --- |
| P0 工作区 | 新建、切换、独立编辑、恢复标签顺序和活动标签；右键关闭、最近关闭重开、确认后永久删除 |
| P0 区域 | 整行选区转换、独立语言选择；共享文档光标、选择、滚动和撤销重做；最后一个区域删除后仍可编辑 |
| P0 保存 | 300–500ms 防抖、原子清单提交、结构变化保存、关闭前最终刷新、重启恢复、保存失败可见且可重试 |
| P0 文本 | 纯文本输入选择、全选、复制剪切粘贴、撤销重做、常见光标键、多行、Tab、查找替换、字体大小 |
| P0 高亮 | 每区域独立配置，切换语言和主题不修改文本；仅提供实际可用的语法 |
| P1 文件 | UTF-8/BOM，尽合理成本支持 UTF-16 LE/BE；打开为新工作区，显式写回关联路径或导出 |
| P1 查找 | 当前文档内计数、大小写、前后匹配、替换当前、全部替换；正则和全词为可选增强 |
| P1 外观 | 深浅主题、字号、焦点提示、窗口尺寸和布局恢复、中文文案集中管理 |

查找替换、字号和基本文件互操作虽然在原需求部分位于 P1 描述中，仍属于最终核心版本验收项，不能以优先级为由省略。

## 内容与文件规则

- Workspace 是 Tab，不是文件；显示标题可以自动生成，无需用户维护文件名。
- EditorRegion 是唯一的文本和语言归属单位，禁止在工作区级共用唯一语言。
- 内部 JSON 工作区文件是默认持久化位置，使用系统标准用户数据目录，不使用工作目录或安装目录。
- 自动保存仅更新内部恢复副本，绝不自动覆盖关联的外部文件。
- Ctrl/Cmd+S 对关联区域显式写回文件；对临时区域刷新内部保存并提示状态，不弹出另存为。
- 导出由用户主动发起；导出成功后是否建立关联必须在 UI 中明确，计划默认仅导出副本。
- 高亮、行号、标题和语言标签都不进入真实文本或剪贴板。复制仅提供纯文本，粘贴忽略富文本。
- 默认不做换行规范化，不自动 trim、不自动格式化。中文、Emoji、空格、Tab、CRLF/LF/CR 必须验证；控件若有规范化行为，应先验证并提供保真适配再验收。

## 语言清单

目标覆盖 Plain Text、JSON、YAML、TOML、Markdown、Rust、Go、Python、JavaScript、TypeScript、HTML、CSS、SQL、Shell、PowerShell、C/C++、Java、XML、日志。实现时逐项检查 syntect 所选语法包；缺失项引入许可证兼容的真实语法定义并测试，或明确记录缺失，不用纯文本冒充该语言高亮。日志没有通用唯一语法，应明确提供的日志规则或保留纯文本。

## 快捷键规则

| 组合键（macOS 使用 Cmd，Windows/Linux 使用 Ctrl） | 操作 |
| --- | --- |
| N / W | 新建 / 关闭工作区 |
| Tab / Shift+Tab | 下一个 / 上一个工作区 |
| F / H | 查找 / 替换 |
| Z / Shift+Z（macOS）；Z / Y（Windows/Linux） | 撤销 / 重做 |
| A / C / X / V | 当前区域全选 / 纯文本复制 / 剪切 / 粘贴 |
| S / O | 显式保存 / 打开文件 |
| 加号 / 减号 | 调整字号（覆盖常见键盘上的 Shift+=） |

菜单根据平台展示快捷键；文本编辑命令交给活动控件，全局命令只消费一次事件。查找输入框聚焦时，撤销和剪贴板遵循该输入框焦点，不误改编辑区。

## 暂不扩展

不实现云同步、账号、富文本、插件运行时、文件比较和完整 IDE。保留模块扩展点即可，不提前引入复杂异步框架、通用插件架构或大型编辑器内核。

当前存储要求以 [文件存储设计](12-file-storage-design.md) 为准，旧 SQLite 要求已经用户确认取消。
